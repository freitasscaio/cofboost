Política de Privacidade

Última atualização: 28 de outubro de 2026

Resumo
  • O site não tem formulários. Ele só usa cookies e o Google Analytics se você aceitar no aviso de cookies; se recusar, nada disso é ativado.
  • Fontes e imagens são servidas pelo próprio site. O Google Analytics só é carregado depois do seu aceite.
  • A empresa de hospedagem registra dados técnicos de acesso (como o endereço IP) para entregar e proteger o site.
  • O aplicativo CofBoost não envia dados pessoais para nós. Ele só consulta o GitHub para saber se há versão nova, e isso pode ser desligado.

Como agente de tratamento de pequeno porte, o responsável pode não indicar um encarregado (Resolução CD/ANPD nº 2/2022); este canal cumpre a função de comunicação com os titulares e com a Autoridade Nacional de Proteção de Dados (ANPD).

2. O que acontece quando você visita o site

2.1 Cookies e o aviso de consentimento

Sem o seu aceite, o site não grava cookies. Ele guarda apenas a sua resposta ao aviso de cookies (aceitou ou recusou, com a data) no armazenamento local do seu navegador, para não perguntar de novo a cada visita. Esse registro fica só no seu navegador e não é enviado a ninguém.

2.2 Google Analytics (só com o seu consentimento)

O site usa o Google Analytics 4, do Google, para contar visitas e entender quais páginas são mais úteis. Ele só é ativado depois que você clica em Aceitar no aviso de cookies. Se você clicar em Recusar, ou não responder, o script do Google não é carregado e nenhum cookie de medição é gravado.

2.4 Links para outros sites

O botão de download e os links de código levam ao GitHub (GitHub, Inc.). Ao clicar, você passa a navegar no GitHub, e a política de privacidade dele se aplica. Os links para redes sociais funcionam da mesma forma.

3. O que acontece quando você usa o aplicativo

O CofBoost roda no seu computador e não envia dados pessoais, de uso ou de hardware para o responsável pelo projeto. Na prática:

  • Dados guardados só no seu PC: o backup dos valores originais das configurações alteradas, as suas preferências e um registro de atividades ficam na pasta ProgramData\CofBoost. Eles servem para o botão Desfazer e para você conferir o que o app fez. Você pode apagá-los quando quiser; o desinstalador oferece reverter as otimizações e remover essa pasta.
  • Informações do computador: o modelo do processador, da placa de vídeo, a memória, o disco e a versão do Windows são lidos para aparecer no Painel do app e não saem do seu PC.
  • Verificação de atualização: ao abrir, o app consulta o GitHub (api.github.com) para saber qual é a versão mais recente. Como em qualquer conexão com a internet, o GitHub recebe o endereço IP do seu computador. Você pode desligar essa verificação em Configurações.
  • Atualização e download: quando você clica em Atualizar agora, o instalador é baixado do GitHub, que também recebe o endereço IP.

4. Compartilhamento

O responsável pelo projeto não vende, aluga nem compartilha dados pessoais. Os únicos terceiros envolvidos são os citados acima: a hospedagem do site, o GitHub e, só se você aceitar, o Google Analytics, cada um como prestador do próprio serviço.

5. Por quanto tempo

O responsável pelo projeto não mantém bancos de dados com informações de visitantes ou usuários. Os registros técnicos ficam com a hospedagem pelo prazo definido por ela, e os dados do Google Analytics pelo prazo indicado na seção 2.2. Os dados do aplicativo ficam no seu computador até você apagá-los ou desinstalar o app.

6. Seus direitos

A LGPD (art. 18) garante a você, entre outros, os direitos de confirmar se há tratamento dos seus dados, acessá-los, corrigi-los, pedir anonimização, bloqueio ou eliminação, saber com quem foram compartilhados e se opor a um tratamento. Para exercer qualquer um deles, escreva para [E-MAIL DO PROJETO]. Como o projeto praticamente não guarda dados pessoais, a resposta pode ser de que não há dados seus conosco; pedidos sobre os registros da hospedagem ou do GitHub também podem ser feitos diretamente a essas empresas.

Você também pode apresentar reclamação à ANPD pelo site gov.br/anpd.

7. Crianças e adolescentes

O site e o aplicativo não pedem nem coletam dados de crianças ou adolescentes. O uso do aplicativo exige permissão de administrador do computador; menores de idade devem usá-lo com o acompanhamento dos responsáveis.

8. Segurança

O site é servido por conexão segura (HTTPS) e só carrega um script de terceiros, o do Google Analytics, depois do seu consentimento. O aplicativo confere a integridade de cada atualização (SHA-256) antes de instalar e tem o código aberto para auditoria.

9. Mudanças nesta política

Esta política pode ser atualizada, por exemplo se o site passar a usar alguma ferramenta nova. A data no topo indica a versão em vigor, e mudanças relevantes serão destacadas no site.
